# Monitor Terrarium (Client)

데스크톱 화면 하단에 항상 떠 있는 1280×240 투명 오버레이 위에서 캐릭터가 돌아다니고
같은 방(room)에 접속한 사람들끼리 실시간으로 채팅하는 Godot 4 클라이언트입니다.

> 서버 실행 가이드는 서버 레포(SV) 담당 영역이라 이 문서에서는 다루지 않습니다.

## 요구 사항

- **Godot 4.6** (Forward+ 렌더러)
  - [godotengine.org/download](https://godotengine.org/download) 에서 4.6 버전을 받습니다.
  - 별도 빌드 도구나 의존성 설치는 필요 없습니다. (순수 GDScript)

## 프로젝트 열기 / 실행

1. Godot 4.6을 실행합니다.
2. **Import** (또는 프로젝트 매니저의 가져오기)를 눌러 이 저장소의 `project.godot` 파일을 선택합니다.
3. 프로젝트가 열리면 상단 우측의 **▶ 실행**(F5) 버튼을 누릅니다.
   - 시작 씬은 메뉴 화면(`menu.tscn`)으로 지정되어 있어, 실행하면 1280×720 메뉴 창이 먼저 뜹니다.

명령줄에서 바로 실행하려면:

```bash
# 저장소 루트에서
godot --path .
```

## 서버 접속 주소(WS_URL) 변경

접속할 서버 주소는 [`main.gd`](main.gd) 상단 상수에 하드코딩되어 있습니다.

```gdscript
const WS_URL := "ws://13.209.96.232:8080/ws"
```

다른 서버(예: 로컬에서 띄운 서버)에 붙으려면 이 값을 바꾸세요.

```gdscript
# 예: 로컬 서버
const WS_URL := "ws://127.0.0.1:8080/ws"
```

- 프로토콜은 평문 `ws://` 입니다. TLS 서버라면 `wss://` 로 변경합니다.
- 변경 후 다시 실행하면 새 주소로 접속을 시도하며, 끊기면 자동으로 재연결합니다.

## 사용법

### 1. 메뉴 화면

실행하면 먼저 메뉴 창이 뜹니다.

| 입력칸 | 설명 | 기본값 |
| --- | --- | --- |
| **room code** | 접속할 방 코드. 영숫자로 입력하면 자동으로 대문자로 변환됩니다. | `ROOM01` |
| **nickname** | 다른 사람에게 보일 닉네임. | `player` |

값을 입력하고 **시작** 버튼을 누르면, 입력값으로 서버에 접속하면서 화면 하단의
투명 오버레이로 전환됩니다. (빈 칸으로 두면 기본값이 사용됩니다.)

같은 room code로 접속한 사람끼리 서로 보이고 채팅할 수 있습니다.

### 2. 오버레이 (게임 화면)

화면 하단에 테두리 없는 투명 오버레이가 항상 위에 떠 있습니다.
좌측 상단에 연결 상태가 표시됩니다.

**조작 / 단축키**

| 키 | 동작 |
| --- | --- |
| **← / →** | 캐릭터 좌우 이동 |
| **Enter** | 채팅 창 열기 |
| **T** | 항상 위(always-on-top) 표시 켜기/끄기 |
| **C** | 감상 모드(클릭 통과) 켜기/끄기 — 켜면 오버레이가 마우스를 통과시켜 뒤쪽 창을 조작할 수 있습니다. 다시 **C** 로 해제 |
| **ESC** | 앱 종료 |

> 화면 우측 상단의 **💬 버튼**으로도 채팅 창을 열고 닫을 수 있습니다.

**시스템 트레이**

실행 중에는 트레이(메뉴 막대)에 아이콘이 등록됩니다. 아이콘을 클릭하면
**종료** 메뉴로 앱을 끌 수 있습니다.

### 3. 채팅

- **Enter** 또는 **💬 버튼**으로 별도의 채팅 창을 엽니다.
- 채팅 창에는 이전 대화 기록과 입력칸, **전송** 버튼이 있습니다.
- 메시지를 입력하고 **Enter** 또는 **전송** 버튼을 누르면 전송됩니다.
  - 전송한 메시지는 채팅 창 기록에 남고, 동시에 내 캐릭터 위에 말풍선으로 5초간 표시됩니다.
- 채팅 창에서 **ESC** 를 누르면 창이 닫힙니다.

> ⚠️ **한글 입력 참고**: macOS/Linux의 Godot IME 특성상 한글 등 조합 문자는
> **Enter** 한 번으로 전송이 안 될 수 있습니다. 이 경우 **전송 버튼**을 사용하면
> 어느 OS에서나 동일하게 전송됩니다. (Windows 동작은 별도 검증 중)
